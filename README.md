# Construction Website Demo — رُكن البناء

Arabic RTL construction-company website demo for showcasing web design skills.

## Publish with GitHub Pages
1. Create a **public** repository named `construction-website`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and use the displayed URL.

## Demo notes
- Contact details are placeholders.
- Contact form is front-end demo only; connect it to a form service or WhatsApp before using it for real client leads.
- Images are remote and require internet access.
